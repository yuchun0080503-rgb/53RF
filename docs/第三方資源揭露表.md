# ResearchFlow 第三方資源揭露表

依競賽辦法第十三條第四款：使用開源軟體、模型、資料集、API、生成式 AI 或第三方內容者，揭露來源、用途及範圍。
最後更新：2026-11-10（依 GitHub main 與待合併分支的程式碼整理）

## 一、生成式 AI 與模型

| 名稱 | 提供者 | 版本 | 用途 | 送出的資料 | 呼叫方式與控管 | 失效時 |
|---|---|---|---|---|---|---|
| Claude Haiku 5.5 | Anthropic | `claude-haiku-5-5`（設定在 `functions/proxy.js` 的 `MODELS`） | 判斷研究範圍與聚焦提問、草擬研究問題、規劃搜尋關鍵字、翻譯關鍵字、逐篇判讀文獻（相關度與立場）、文獻重點整理、手寫辨識校正、投影片文字大綱 | 白板文字、小組的主張與研究問題、文獻標題與摘要、手寫筆跡圖片 | 只經過我們的 Firebase Cloud Function（`/api/ai`）：要登入、要是該研究的 Owner／Editor、老師設定的 AI 權限 ≥ Level 1、全站每日 2000 次上限；金鑰存在 Secret Manager，不在網頁或程式碼裡 | 改用內建規則式程式，畫面標示「AI：未連線（規則式）」 |
| Claude 網路搜尋工具 `web_search_20250305` | Anthropic | 同上模型 | 中文文獻搜尋：只搜尋華藝線上圖書館（airitilibrary.com）與臺灣博碩士論文知識加值系統（ndltd.ncl.edu.tw） | 中文關鍵字 | Cloud Function `zhsearch`：網域白名單；回傳前核對網址確實出現在搜尋結果、網域正確、標題相符；每專案只在第 1 輪查一次 | 不影響英文資料庫的結果 |

開發過程使用的生成式 AI 工具（不在系統執行時使用）：Claude（Anthropic）與 Codex（OpenAI）協助撰寫程式、測試與文件；功能需求、設計決策與驗收由組員決定與確認。

## 六、不使用的
- 不使用任何付費資料庫或需要登入的學術資料庫帳號。
- 不把學生內容用來訓練模型；Anthropic API 的資料使用依其商業條款。
