## 1. 系統架構

```
瀏覽器（researchflow.html + src/*.mjs，單頁網站）
 ├─ Firebase Auth（登入）
 ├─ Firestore（研究、畫布、Agent 狀態、歷程、課程、留言）←→ 即時同步給組員
 ├─ Cloud Storage（圖片、錄音）
 ├─ /api/ai       → Cloud Function ai       → Anthropic Claude API
 ├─ /api/zhsearch → Cloud Function zhsearch → Claude 網路搜尋（華藝、臺灣博碩士論文網）
 ├─ /api/openalex → Cloud Function oaproxy  → OpenAlex（後端帶金鑰、24 小時快取）
 ├─ /api/jstage   → Cloud Function jstage   → J-STAGE
 └─ 直接連線：Crossref、ERIC、Europe PMC、DOAJ、OpenAIRE、Semantic Scholar、翻譯與手寫辨識服務
```

| 檔案 | 內容 |
|---|---|
| `researchflow.html` | 畫面與互動（畫布、Agent 面板、證據、老師端、留言、錄影錄音、圖片） |
| `src/agent-local.mjs` | 規則式 Agent：判斷範圍、研究問題、搜尋與篩選文獻（AI 失效時的備援） |
| `src/agent-llm.mjs` | 交給 Claude 的步驟與提示詞：關鍵字規劃、文獻判讀、重點整理、投影片大綱等 |
| `src/llm.mjs` | 前端呼叫 `/api/ai` 的共用程式 |
| `src/sources.mjs`、`src/searchLogic.mjs` | 各資料庫的查詢網址、結果整理、依學科分流 |
| `src/db.mjs` | Firestore／Storage 讀寫、權限檢查（guard）、Agent 流程串接 |
| `src/course.mjs` | 課程代碼產生與有效期限 |
| `src/ink.mjs` | 手寫筆畫分段、辨識、圖形偵測 |
| `functions/` | Cloud Functions：`proxy.js`（Claude 代理與使用檢查）、`openalex.js`、`zhsearch.js`、`jstage.js` |
| `firestore.rules`、`storage.rules` | 伺服器端權限規則 |
| `tools/eval/` | Agent 評測程式與測試題（40 題） |

## 2. Agent 流程（每一步都要學生確認）

1. **讀取畫布**：手寫先辨識成文字，學生確認。
2. **判斷研究範圍與聚焦提問**：Claude 提出 3 個左右的聚焦問題（對象、情境…），學生選擇或自填。
3. **研究問題**：Claude 依畫布與聚焦答案草擬，學生可改。
4. **搜尋策略**：Claude 規劃主題詞、範圍詞、觀點詞與學術英文同義詞；依學科決定加查哪些資料庫；老師可指定可信任資料庫。
5. **搜尋證據（最多 3 輪）**：查詢各資料庫 → 程式先篩掉沒提到主題詞的 → Claude 逐篇讀摘要判斷相關度與立場（支持／反向／立場待確認）→ 不夠就反思並放寬條件再查。
6. **整理**：每篇證據產生重點整理；學生確認分類、加入畫布、產生投影片大綱（Level 3）。

AI 失效時每一步都有規則式備援，畫面會標示目前是 Claude 還是規則式。

## 3. 模型與版本

- Claude Haiku 5.5（`claude-haiku-5-5`）：文字步驟與手寫校正，設定在 `functions/proxy.js` 的 `MODELS`；中文網路搜尋在 `functions/zhsearch.js`。
- 輸出格式：用「強制工具呼叫」讓模型輸出一定符合 JSON Schema。
- 提示詞版本管理：提示詞寫在 `src/agent-llm.mjs`、`functions/zhsearch.js`，透過 Git 版本控制，每次修改都經 Pull Request 合併，並附評測結果。

## 4. 安裝與執行

**本機預覽（不需要任何帳號）**
```
npm install
npm start          # http://localhost:5173，沒有 Firebase 設定時自動進入展示模式（示範資料、不儲存）
npm test           # 單元測試
```

**部署到自己的 Firebase 專案**
1. 建立 Firebase 專案，啟用 Authentication（電子郵件、Google）、Firestore、Storage；Cloud Functions 需要 Blaze 方案。
2. 複製 `src/firebase-config.example.js` 為 `src/firebase-config.js`，填入專案設定（這些值是公開識別碼，不是密碼）。
3. 設定後端金鑰：
   ```
   firebase functions:secrets:set ANTHROPIC_API_KEY
   firebase functions:secrets:set OPENALEX_KEY     # 選填，沒有也能用，只是額度較小
   cd functions && npm install && cd ..
   ```
4. 部署：`firebase deploy --only hosting,firestore:rules,storage,functions`
5. Storage 規則會讀取 Firestore 的成員名單：第一次部署後到 Firebase Console → Storage → 規則，若出現跨服務呼叫的警告，按「解決問題」→「附加權限」。

## 5. 環境變數與設定

| 名稱 | 放在哪 | 用途 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Secret Manager | Claude API 金鑰（`ai`、`zhsearch`） |
| `OPENALEX_KEY` | Secret Manager | OpenAlex 金鑰（`oaproxy`） |
| `src/firebase-config.js` | 前端（不進 Git） | Firebase 專案識別碼 |
| `SITE_PER_DAY`（`functions/proxy.js`） | 程式常數 | 全站每日 AI 呼叫上限，預設 2000 |

程式碼與文件不含任何密碼或金鑰。

## 6. API（網站同網域，Firebase Hosting 轉給 Cloud Functions）

| 路徑 | 方法 | 需要 | 說明 |
|---|---|---|---|
| `/api/ai` | POST | 登入憑證、`projectId` | 送出 `{tier, system, user, schema, maxTokens}`，回傳符合 schema 的 JSON |
| `/api/zhsearch` | POST | 登入憑證、`projectId` | 中文文獻網路搜尋，回傳核對過的文獻清單 |
| `/api/openalex` | GET | 登入憑證 | OpenAlex `/works` 查詢代理，參數白名單 |
| `/api/jstage` | GET | 登入憑證 | J-STAGE 查詢與摘要擷取 |

## 9. 已知限制
- AI 判讀只根據摘要，不讀全文；摘要沒寫結果的文獻列為「立場待確認」。
- 中文文獻只能透過網路搜尋取得華藝、臺灣博碩士論文網的摘要片段，沒有正式 API。
- 手寫辨識對潦草、字黏在一起的筆跡仍會認錯，結果一律要學生確認。
- 全站每日 AI 上限 2000 次，一整班同時使用可能用完，用完後改用規則式。
- 老師身分是「建立課程的人」，系統沒有另外驗證教師身分。
- 圖片、錄音的網址本身就像通行證，拿到網址的人可以直接開啟。
- 多人同時改同一個物件時，最後寫入的會覆蓋前面的。

## 10. 故障排除

| 狀況 | 原因與處理 |
|---|---|
| 畫面顯示「AI：未連線（規則式）」 | 沒登入、展示模式，或後端連不上；確認已登入，並看 Firebase Console 的 Functions 記錄 |
| AI 回「你不是這份研究的成員」 | 只有 Owner／Editor 能用 AI；老師與 Viewer 不行 |
| AI 回「今天全站的 AI 額度已用完」 | 達到每日上限，隔天台灣時間 0 點重置；或調高 `SITE_PER_DAY` 後重新部署 |
| 搜尋結果很少、訊息提到 Crossref | OpenAlex 額度用完或代理失效，已自動改查 Crossref |
| 圖片或錄音上傳失敗 | 確認是 Owner／Editor、檔案 20MB 以內；Storage 規則的跨服務權限是否已附加（見第 4 節第 5 步） |
| 密碼登入失敗，但以前能登入 | 曾用同一信箱按過 Google 登入，Firebase 會取消密碼；改按 Google 登入，或按「忘記密碼」重設 |
| 錄影或錄音按了沒反應 | 瀏覽器不支援或沒允許麥克風；請用新版 Chrome、Edge 或 Safari，並允許麥克風 |
